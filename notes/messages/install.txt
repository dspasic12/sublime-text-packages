.notes — getting started
========================

Command Palette (Cmd/Ctrl+Shift+P) → type  .notes

Daily journal
  ~/Documents/ST4Notes
  (created if missing; User setting notes_file if OneDrive / localized Documents)

Knowledge base (separate package: kb)
  Command Palette → type  .kb
  File: ~/Documents/ST4Notes-kb
  Overlap with notes: insert / hover  kb:topic/subject

First 30 seconds
  1. .notes - View              journal (read-only)
  2. Alt+Up / Alt+Down          select a # HEADER:
  3. Enter                      edit that day's block in a slice
  4. .notes - Add → New note    topic: any heading, then bullets
  5. Cmd/Ctrl+Shift+Enter       commit a slice

Slices
  Note / Issue open a scratch "slice".
  Fields sit above --- ; body below. Alt+Up/Down cycles fields.
  View+Enter replaces that day's header block.
  Add → existing header, or New note, appends under today.

YouTrack / GitLab (optional)
  Preferences → Package Settings → notes → Settings – User
  youtrack_base, youtrack_token, default_project
  gitlab_base, gitlab_token
  Never put tokens in the package defaults.

Re-open this page:  .notes - Hub → Getting started

Requires Sublime Text 4, Python 3.14 plugin host (build 4205+).
Package folder name must be "notes".
